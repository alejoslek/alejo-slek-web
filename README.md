# Alejo Slek · Páginas web y sistemas en Córdoba

Mi web de presentación: **https://alejo-slek.netlify.app**

Hago páginas web y sistemas a medida para pymes y emprendimientos de Córdoba (Argentina): la web donde te encuentran, el análisis de cómo trabaja el negocio y herramientas para ordenar el día a día.

## Qué hay acá
- `index.html`: la portada (HTML, CSS y JavaScript, sin frameworks).
- `proyectos/`: tres webs de práctica, con negocios y datos ficticios:
  - `turnos/`: Veterinaria Mandarina, con una agenda de turnos real de Google Calendar.
  - `enfermeria/`: Cuidar en Casa, enfermería a domicilio.
  - `barberia/`: Filo Barbería.
- `img/`: miniaturas de los trabajos y la imagen para compartir.
- `_headers`: reglas de seguridad para el navegador (Content-Security-Policy, HTTPS y bloqueo de marcos, entre otras).
- `sitemap.xml`, `robots.txt` y `404.html`: para Google y para las direcciones que no existen.

## Cómo se publica
Es un sitio estático alojado en Netlify (plan gratis). Se sube la carpeta tal cual, sin ningún paso de compilación.
